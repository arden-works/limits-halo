# LimitsHalo v0.1.0-beta

## English

First public beta release of **LimitsHalo**.

LimitsHalo keeps your remaining **Codex 5-hour and weekly limits visible directly on the Windows taskbar**.

### Highlights

- Windows installer included
- Live Codex Desktop limit data
- No API key required
- Taskbar limit display
- Codex quick open/focus from the taskbar
- Settings, manual refresh and startup controls
- English and Turkish interface
- Clean install and uninstall verified on Windows 11
